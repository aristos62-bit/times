## Part B — 4 αποκλίσεις Drift codegen (σημαντικό — καταγράφηκαν στο DESIGN.md)
1. **Helper `utcDateTime()` ΑΠΟΡΡΙΦΘΗΚΕ** από τον codegen
   ("type 'Null' is not a subtype of type 'MethodInvocation'") → όλες οι
   στήλες ημερομηνιών INLINE: `dateTime().map(const UtcDateTimeConverter())()`.
2. **`withDefault(currentDateAndTime)` ασύμβατο** με mapped DateTime columns
   (warning "Parameter must accept DateTime") → αφαιρέθηκε παντού· τα
   createdAt/updatedAt μπαίνουν ρητά από app/DAO/seed.
3. **Converter `TypeConverter<DateTime, DateTime>`**, όχι `<DateTime, String>` —
   το `storeDateTimeAsText: true` διαχειρίζεται ήδη το DateTime↔String· ο
   converter κάνει ΜΟΝΟ UTC↔local.
4. **`afterOpen` ΔΕΝ υπάρχει** σε drift 2.14 → `beforeOpen`.
- Docs-only παρατήρηση (ΔΕΝ άλλαξε, θέλει έγκριση): `Categories.unique(name,
  parentId)` με NULL parentId δεν μπλοκάρει διπλά root ονόματα (SQLite
  NULL semantics)· `ReceiptItems` χωρίς unique `(receiptId, itemId)`.

### Βήματα (εγκρίθηκαν από χρήστη, ένα-ένα)
1. **Fix #1 — `BudgetDao._monthBounds` (ΣΟΒΑΡΟ):** τα όρια μήνα υπολογίζονταν
   με γυμνά strings ημερομηνίας (`'2026-05-01'`). Η βάση αποθηκεύει πλήρες UTC
   ISO (`receiptDate` → `'2026-04-30T21:00:00.000Z'` για 1/5 τοπικά στην Αθήνα),
   άρα μια απόδειξη της 1ης το πρωί ήταν λεξικογραφικά < όριο → έπεφτε στον
   ΠΡΟΗΓΟΥΜΕΝΟ μήνα. Διόρθωση:
   `start = DateTime(year, month, 1).toUtc().toIso8601String()`,
   `end = DateTime(year, month + 1, 1).toUtc().toIso8601String()`.
   Ο Dart constructor κάνει roll-over για month=13 → αφαιρέθηκε το ειδικό case
   (Δεκέμβριος). Μία αλλαγή καλύπτει watchBudget/watchBudgetsForMonth/
   watchDashboardSpending (όλα καλούν το _monthBounds).
2. **Fix #2 — `ItemDao.increaseStock`:** το `variable<DateTime>(DateTime.now())`
   σε `ItemsCompanion.custom` παρακάμπτει τον UtcDateTimeConverter → αποθήκευση
   τοπικής ώρας αντί UTC. Διόρθωση: `DateTime.now().toUtc()`.
3. **Fix #3 — `SettingDao.setSetting`:** `insertOrReplace` στη UNIQUE σύγκρουση
   = DELETE+INSERT → νέο `id` κάθε φορά. Διόρθωση: `onConflict: DoUpdate(...,
   target: [userSettings.key])` → id μένει σταθερό (ίδιο pattern με το budget).
4. **Fix #4 — `CategoryDao.createCategory`:** το SQLite UNIQUE(name, parentId)
   ΔΕΝ μπλοκάρει δύο ρίζες (parentId=NULL) με ίδιο name (NULLs distinct).
   App-level έλεγχος πριν το insert (ρίζα-ρίζα ή ίδιος parentId) →
   `CategoryDuplicateNameException`. (#5: softDelete void/bool — απόφαση:
   παραμένουν ως έχουν, δεν αλλάζουν.)
5. **Tests:** +3 boundary στο budget_dao_test (1η του μήνα τοπικό μεσονύχτι,
   30/4 23:59:59.999, Δεκ 31 23:59:59.999 + 1/1) + 3 duplicate στο
   category_dao_test (ρίζα duplicate, υποκ. duplicate, διαφορετικός parent OK).
   = **206/206** · `flutter analyze`: No issues found.
