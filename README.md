# Τιμές (Times)

Personal expense & receipt tracking with price history and store comparisons.

Προσωπική καταγραφή αγορών/αποδείξεων, παρακολούθηση τιμών ειδών ανά προμηθευτή, στατιστικά και συγκρίσεις τιμών στον χρόνο.
